LumenRise is live on Base. Bonding curves, presales, and auctions all run there. The Base app is audited, production launches are open, and the launchpad has done more than $10k in volume.

Stellar is the expansion network. This documentation still carries the Stellar factory, vault, and reputation details so that integration work can start before that network matches Base.

The review below is dated **28 October 2026**.

## Feature availability

| Capability | Base | Stellar |
| --- | --- | --- |
| Bonding-curve factory and dedicated vaults | Live | Implemented in contract source. Mainnet factory address published. |
| Buy and sell quotes, price movement, slippage limits | Live | Implemented in contract source. |
| Presales | Live | Product format documented. Stellar sale contracts are part of the expansion. |
| Auctions | Live | Product format documented. Stellar sale contracts are part of the expansion. |
| Scheduled opening | Live | Implemented in contract source. No trading deadline on the current curve. |
| Pool, curve, and team allocation accounting | Live | Implemented in contract source. |
| Team cliff and stepped vesting | Live | Implemented in contract source. |
| Creator trading-fee claims | Live | Implemented in contract source. |
| Graduation | Live on Base | Implemented. Graduation stops curve trading. Settlement and pool creation are still source-limited on Stellar. |
| Reputation scores, labels, and purchase gating | Access rules on the launch | Implemented in contract source. Scores are written by the registry admin. |
| Automatic X, GitHub, and onchain scoring | Not the Base path | Planned. No production scoring service is present. |
| Public app and wallet login | Live | Prototype interface with Blux. |
| Public HTTP API, packaged SDK, launch CLI | Planned across networks | Planned. The shared Rust reputation client exists. |

## How to read the rest of these docs

Product guides (formats, creators, participants) describe the live Base launchpad first, then note Stellar where the path differs.

Developer pages under Stellar contracts still describe the Soroban factory, vault, and reputation ABIs. That is intentional. Those pages are the Stellar expansion reference, not a claim that Stellar already matches every Base feature.
