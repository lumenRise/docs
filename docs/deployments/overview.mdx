Use this directory to select a network and verify a contract version. An address is meaningful only together with its network and deployed code.

## Networks

| Network | Current record | Details |
| --- | --- | --- |
| Testnet | Historical 8 October 2026 fixtures; no verified deployment of the current source version | [Testnet deployments](/deployments/testnet) |

The historical Testnet report predates reputation gates and the current no-deadline curve lifecycle. It cannot be used as evidence that those features are live.

| Component | Current release record |

## Verify a future release

A deployment record should include the network, deployment time, source revision or release artifact, WASM hash, transaction hash, registry and admin, factory settings, asset identities, and relevant smoke-test evidence.

Read the factory's stored registry and vault hash. Do not assume a known factory has been updated just because the local source changed. Existing vaults are not upgraded by a new factory deployment.

A published address alone does not establish that settlement, liquidity, or claim behavior is complete. Review [implementation status](/getting-started/status) alongside the release record.
