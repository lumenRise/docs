Use this directory to pick a network and copy the right factory. An address is only useful together with its chain.

## Networks

| Network | Current record | Details |

| Base | Live production launchpad. Factory address lives on its own page so you can drop it in. | [Base factory](/deployments/base) |

Base is where the app runs today: bonding curves, presales, auctions, audited contracts, and more than $10k in volume. Stellar is the expansion network.

A Base `0x` factory is not a Stellar `C...` contract. Do not mix the two in a client.

Stellar Testnet assets and funds have no Mainnet equivalence. Testnet resets can remove old contracts and data. Base Sepolia is a separate rehearsal chain and is not the production factory.

## Verify a deployment

A deployment record should include the network, chain ID or passphrase, deployment time, source revision, factory settings, quote asset, and a confirmed transaction.

Read the factory's stored settings before you integrate. Do not assume a known factory has been updated just because local source changed. Existing vaults are not upgraded by a new factory deployment.

A published address alone does not establish that settlement, liquidity, or claim behavior is complete. Review [implementation status](/getting-started/status) alongside the release record.
