## Current release blocker

The curve can reach graduation and permanently stop trading, but it does not release graduation proceeds or create a liquidity pool. The repository explicitly states that the prototype is not ready for a real-money launch. An independent security audit is not supplied.

A configurable Mainnet deployment script is not evidence of a Mainnet release. Neither are source tests, a local build, a preview interface, or historical Testnet fixtures.

## What this page will publish

When a release exists, this page should list the network passphrase, registry and admin, factory and platform configuration, vault code hash, deployment transactions, release revision, and version-specific behavior.

Issued-asset entries should include code, issuer, and SAC address. Links must point to the public network rather than Testnet. Historical deployments should remain clearly separated from the current supported release.

Until that record is available, there is no official Mainnet address in this documentation to configure or fund.
