## Current Stellar release notes

The Stellar curve can reach graduation and stop trading. Graduation proceeds and liquidity-pool creation on that network still need a published settlement path. Check the deployed configuration and contract specification before integrating.

The vault code hash, deployment transactions, release revision, and factory configuration are not yet listed here.

Issued-asset entries should include code, issuer, and SAC address. Links must point to the public network rather than Testnet. Historical deployments should remain clearly separated from the current supported release.
