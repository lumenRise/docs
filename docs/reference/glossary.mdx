---
title: "Glossary"
description: "Terms used across the launch and reputation documentation."
---

| Term | Meaning |
| --- | --- |
| Allocation | An amount assigned to a participant or supply bucket. It may be provisional until settlement. |
| Asset code | The short code of an issued Stellar asset. It identifies the asset only together with its issuer. |
| Auction | A sale where bids express willingness to pay and determine allocation priority under published rules. |
| Basis point, bps | One hundredth of a percent. 10,000 bps equals 100%. |
| Bonding curve | A formula that prices trades using the launch's sold supply and reserve parameters. |
| Claim | A transaction transferring assets that have become available under a schedule or entitlement. |
| Cliff | A delay before vesting begins. |
| Commitment | Quote assets submitted for a future allocation process. It is not necessarily an accepted allocation. |
| Criteria | Threshold conditions evaluated against reputation scores. |
| Distribution account | The account holding the intended launch supply before vault deposit. |
| Graduation | The current curve's terminal trading state after reaching its net reserve target. |
| Issuer | The Stellar account that issues an asset. Its controls matter independently of vault custody. |
| Label | An immutable named set of reputation criteria with a registry-local ID. |
| Mainnet | Stellar's public network, separate from Testnet. |
| Marginal price | The price of the next small increment of an asset, rather than a large trade's average price. |
| Onchain score | A numeric reputation category intended to reflect Stellar account activity. |
| Oversubscription | Eligible demand above the amount a sale will accept or allocate. |
| Presale | A fixed-price raise that assigns assets under its allocation and distribution terms. |
| Quote asset | The asset used for payment and pricing, intended to be XLM or USDC. Called `pair` in the ABI. |
| Registry | The contract storing reputation scores, labels, and administration. |
| SAC | Stellar Asset Contract, the built-in Soroban interface to a native or issued Stellar asset. |
| Sell-back position | The amount an address bought directly and may still sell to the current curve before graduation. |
| Settlement | Final calculation and transfer or entitlement recording for accepted bids, commitments, proceeds, or refunds. |
| Slippage limit | A maximum buy payment or minimum sell receipt that bounds an authorized trade. |
| Stroop or base unit | For the seven-decimal assets used here, one ten-millionth of a whole unit. |
| Testnet | Stellar's testing network, with disposable funds and possible resets. |
| Trustline | An account's ledger relationship allowing it to hold a particular issued Stellar asset. |
| TTL | Time-to-live for Soroban contract data. Long-idle data can require restoration. |
| Vault | A dedicated launch contract holding asset allocations and quote reserves. |
| Vesting | Scheduled release of an allocation over time. |
| Virtual reserves | Synthetic amounts used in the curve's pricing formula, separate from actual held funds. |
