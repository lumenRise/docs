# Launchpad documentation design

Inherited from `../interface/DESIGN.md`: white paper, graphite text, cobalt links, Newsreader headings, Manrope body text, and hairline divisions. This is an extension of the existing Launchpad identity.

The docs are a reading surface. A persistent categorized sidebar, article column, and local table of contents carry the content. The root opens directly into documentation. Tables compare formats and parameters; task guides use ordered steps. Search indexes the built documentation locally. Mobile uses the native Docusaurus navigation drawer and horizontally scrollable data tables.

Self-host the two existing typefaces with their licenses. Keep content surfaces flat. Use amber only for planned feature labels and restrained notices for implementation boundaries. Preserve focus visibility, reduced motion, and sufficient contrast.
